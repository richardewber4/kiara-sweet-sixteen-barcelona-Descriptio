# Kiara Xamana Weber — Sweet Sixteen in Barcelona

A responsive one-page birthday trip site for 28–30 October 2026.

## Publish with GitHub Pages
1. Open Settings → Pages.
2. Set Source to Deploy from a branch.
3. Choose `main` and `/(root)`, then Save.
4. Wait for deployment, then open `https://richardewber4.github.io/kiara-sweet-sixteen-barcelona-Descriptio/`.

Weather is fetched from Open-Meteo when the page loads and when Refresh is clicked. Forecast availability for October 28–30 depends on how far ahead the provider publishes data.
